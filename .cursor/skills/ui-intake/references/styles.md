# UI styles to offer (pick 3-4 relevant, mark one recommended)

- Flat: solid colors, no depth. Fast, clean, safest default.
- Neumorphism: soft extruded surfaces. Looks good, weak contrast; warn about accessibility.
- Glassmorphism: translucent blur panels over a rich background. Needs backdrop-filter support.
- Material: elevation and motion rules from Material Design.
- Minimal / editorial: strong typography, lots of whitespace.
- Bento: card grid of mixed sizes, good for dashboards.
- Neo-brutalism: thick borders, hard shadows, bold colors.
