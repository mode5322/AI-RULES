# Icon libraries to offer (verify current package names and versions in official docs first)

- Lucide: clean outline set, tree-shakeable.
- Phosphor: multiple weights (thin to bold), good flexibility.
- Tabler Icons: very large outline set.
- Heroicons: simple, pairs well with Tailwind.
- Material Symbols: variable font, fits Material and Flutter.
- Iconify: one API over many sets.

Never emoji or keyboard characters as icons.
